# My Static Site

This is a simple static website project designed for deployment on GitHub Pages. It includes a homepage, an about page, and a custom 404 error page. The site is styled using CSS and includes JavaScript for interactivity.

## Project Structure

- `index.html`: The main homepage of the site.
- `about.html`: A page providing information about the site or the author.
- `404.html`: A custom error page displayed for non-existent routes.
- `css/styles.css`: The stylesheet for the website.
- `js/main.js`: The JavaScript file for adding interactivity.
- `assets/fonts`: Directory for font files.
- `assets/svgs`: Directory for SVG images and icons.
- `.github/workflows/pages.yml`: GitHub Actions workflow for deploying the site.
- `CNAME`: File for specifying a custom domain.
- `LICENSE`: Licensing information for the project.
- `package.json`: Configuration file for npm dependencies and scripts.

## Getting Started

To get started with this project, clone the repository and open it in your preferred code editor. You can view the site by opening `index.html` in a web browser.

## Usage

- Modify the HTML files to update content.
- Use `css/styles.css` to change the appearance of the site.
- Add interactivity through `js/main.js`.
